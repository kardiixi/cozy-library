# Cozy Library Social 2.0

Статический сайт + Supabase Auth/Postgres. Не требуется свой сервер.

## Запуск
1. Создай проект на https://supabase.com и открой SQL Editor.
2. Вставь содержимое `schema.sql`, нажми Run.
3. В Supabase → Project Settings → API скопируй Project URL и **publishable/anon** key в `config.js`. Никогда не используй secret/service_role key.
4. В Authentication → URL Configuration укажи адрес опубликованного сайта в Site URL; добавь его в Redirect URLs. Для локального теста можно использовать http://localhost:8000.
5. В Authentication → Providers → Email настрой подтверждение почты. Для теста удобнее подтвердить email; для публичного запуска оставь подтверждение включённым и настрой SMTP.
6. В папке проекта выполни `python -m http.server 8000`, открой http://localhost:8000. Или опубликуй все файлы на GitHub Pages (Settings → Pages → Deploy from branch → main / root).
7. Зарегистрируй двух тестовых пользователей с **разными email**, отправь заявку, прими её и проверь полки.

## Перенос двух книг из 1.1
В старой версии нажми «Скачать резервную копию», сохрани JSON. В новой версии войди в аккаунт → «Импорт из версии 1.1» → выбери JSON. Старую версию не удаляй, пока не проверишь импорт.

## Важное
- Книги доступны только владельцу и принятым друзьям, если `is_private=false`.
- Заметки друга не показываются интерфейсом, **но сейчас доступны через API вместе с видимыми книгами**. Не добавляй туда секретную информацию. Для строгой приватности заметок нужна отдельная таблица и RLS.
- Профили (username, display_name) доступны всем зарегистрированным пользователям.
- Ссылки на внешние обложки могут передавать IP внешним серверам изображений.
- Это MVP: нет блокировки пользователей, модерации и защиты от спама. Не запускай массовую публичную регистрацию до доработки.
